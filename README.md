# 世界in石（GitHub Pages / Android PWA版）

## 公開方法

1. ZIPを解凍する。
2. 中身をGitHubリポジトリの一番上の階層へアップロードする。
3. `index.html` が見える状態でGitHub Pagesを有効にする。
4. AndroidのChromeで公開URLを開き、画面に「＋インストール」が出たら押す。出ない場合はChromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ。

## 安全性チェック

- 外部のJavaScript、広告、ログイン、通信APIを使用しない。
- カメラ、マイク、位置情報、連絡先などの端末権限を要求しない。
- 音声ファイルとゲーム本体はGitHub Pagesから読み込み、ゲーム中のデータを外部へ送信しない。
- Service Workerで同じゲームを端末内にキャッシュし、通信が一時的に切れても起動しやすくしている。
- 隕石・爆発・「人類滅亡」の表現は、子ども向けに過度な恐怖表現にならないよう抑えている。

## 音声

- `Quo_Vadis.mp3`：プレイ中のBGM
- `爆発1.mp3`：隕石が落ちた時の効果音

Androidでは自動再生制限があるため、最初に画面をタップするとBGMが始まります。
